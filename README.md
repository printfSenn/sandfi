# Sandfi

Sandfi is an interactive lofi ambience page built around a living sand surface.

## Features

- Interactive sand traces and presses
- 100+ lofi queue entries
- Mood scenes for Focus, Rainy, Night, Sunset, Dust, and Mist
- Optional music visualizer
- Favorites and local playlists stored in the browser
- English and Indonesian interface
- Keyboard shortcuts for playback, queue, favorites, and visualizer

## Development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
